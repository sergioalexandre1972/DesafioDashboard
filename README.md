
# 📊 Projeto de Dashboard Dinâmico no Excel

Este projeto tem como objetivo a criação de um **dashboard dinâmico** no Microsoft Excel, utilizando uma base de dados de assinantes de serviços digitais.

## 📁 Arquivos

- `DashboardXbox.xlsx`: base de dados original fornecida.
- `README.md`: este arquivo de documentação.

## 🧩 Funcionalidades do Dashboard

O dashboard inclui:

- Total de assinantes
- Receita total arrecadada
- Média dos cupons aplicados
- Distribuição dos planos de assinatura (Core, Standard, Ultimate)
- Receita por tipo de assinatura (Mensal, Anual, Trimestral)
- Segmentações para:
  - Tipo de assinatura
  - Renovação automática
  - Participação nos passes EA Play e Minecraft

## 📈 Recursos Utilizados

- Tabela dinâmica (Pivot Table)
- Gráficos dinâmicos (Pivot Chart)
- Segmentações (Slicers)
- Tabela estruturada (Excel Table)

## 🔧 Como Usar

1. Abra o arquivo `dashboard.xlsx` no Microsoft Excel.
2. Selecione a base de dados e crie uma **tabela** (Inserir > Tabela).
3. Vá em **Inserir > Tabela Dinâmica** e crie suas análises.
4. Use **segmentações** para interatividade.
5. Insira **gráficos dinâmicos** para visualizações automáticas.

## 🎯 Objetivo

Este projeto tem caráter **educacional**, com o objetivo de praticar a criação de dashboards dinâmicos no Excel e explorar recursos visuais para análise de dados.

## ✅ Requisitos

- Microsoft Excel 2016 ou superior
- Conhecimento básico em tabelas dinâmicas e gráficos
